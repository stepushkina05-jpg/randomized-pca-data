# Datasets

Datasets for the scRNA pipelines benchmark
## Upstream

This repository is adapted from the OmniBenchmark `omni-scrna/1-data`
data-loading module:

https://github.com/omni-scrna/1-data

The upstream module was originally derived from `scrna-bench/datasets`.

This fork adapts the DATA stage for the randomized PCA benchmark and
adds the datasets used in that benchmark.
